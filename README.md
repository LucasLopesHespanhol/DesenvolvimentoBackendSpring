# Desenvolvimento Backend com Spring ☕🌱

Repositório destinado aos estudos, atividades e projetos desenvolvidos durante a disciplina **Desenvolvimento Backend com Spring**.

O repositório acompanha a evolução das aulas, desde os fundamentos do Java e Spring até a construção de APIs e conceitos relacionados à arquitetura e robustez de aplicações backend.

## 📚 Sobre a disciplina

A disciplina utiliza **Java, Spring Framework e Spring Boot** como base para o desenvolvimento de aplicações backend.

Durante as aulas, são apresentados os conceitos fundamentais do ecossistema Spring, como **Inversão de Controle (IoC)**, **Injeção de Dependência (DI)**, autoconfiguração e organização de aplicações utilizando frameworks.

Também são desenvolvidas aplicações web utilizando a camada **Controller**, trabalhando com APIs REST, requisições HTTP, parâmetros, respostas e códigos de status.

Ao longo da disciplina, os conteúdos avançam para questões de **robustez, tolerância a falhas, escalabilidade e arquitetura de sistemas**, incluindo conceitos de monólitos, microsserviços e sistemas distribuídos.

## 🧠 Conteúdos estudados

* ☕ Java e JVM
* 🌱 Spring Framework e Spring Boot
* 🔄 IoC e Injeção de Dependência
* 🌐 APIs REST e Controllers
* 📡 Métodos e status HTTP
* 🏗️ Arquitetura de aplicações
* 🚀 Robustez e escalabilidade
* 🔗 Monólitos, microsserviços e sistemas distribuídos

> A lista será atualizada conforme novos conteúdos forem abordados durante a disciplina.

## 📂 Estrutura

O projeto será organizado de acordo com a evolução das aulas e dos exercícios desenvolvidos ao longo da disciplina.

## 🎯 Objetivo

Registrar a evolução prática do aprendizado em **desenvolvimento backend com Spring**, reunindo os conhecimentos e aplicações desenvolvidos durante a disciplina em um único repositório.
